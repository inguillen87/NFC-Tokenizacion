# S6 — Retiros y evidencia: avance

Cierre en esta entrega: informe real del piloto, consultable por empresa/lote,
con fuentes, períodos, denominadores y exportación del mismo corte a HTML/CSV/JSON.
No se estima ROI, factura ni audiencia a partir de TAPs.

Pendiente para cerrar S6 completo: detectar/delimitar un retiro comercial, aprobación,
aviso público separado del estado de autenticidad, tareas para distribuidores,
acuses, devoluciones y cierre con evidencia. Cuarentena del producto y revocación
de etiqueta comprometida no son la misma operación.

S5 conserva el kit privado y adaptador CSV entregados; integración nativa real con
el ERP/WMS/POS de un cliente todavía requiere definir el sistema y validar el caso.
S7 no se activa automáticamente: consentimiento, revisión, presupuesto y resultados
antes de enviar campañas. Se mantienen Free y los flujos NFC/GS1/QR ya operativos.
